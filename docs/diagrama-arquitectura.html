go-saas-api — Arquitectura de Microservicios

Backend SaaS multi-tenant para chat AI | Go 1.24 + PostgreSQL + Redis + NATS

Frontend (Vercel)

  • • React 19 + TypeScript
  • • Vite 7 + Tailwind 4
  • • Zustand + Socket.IO
  • • Streaming SSE/WebSocket

API Gateway (Go)

  • • Gin + Reverse Proxy
  • • JWT Validation
  • • Rate Limiting (Redis)
  • • Request ID Propagation

Chat Service (Go)

  • • SSE + WebSocket Streaming
  • • Go Routines per Connection
  • • Connection Pooling HTTP
  • • Fallback entre Providers

Auth Service (Go)

  • • JWT + Refresh Tokens
  • • OAuth Google/GitHub
  • • Sessions en Redis
  • • Password Hashing (bcrypt)

Billing Service (Go)

  • • Stripe SDK (stripe-go)
  • • Subscriptions + Plans
  • • Webhooks (invoice, cancel)
  • • Grace Period + Downgrades

Infraestructura

  • • PostgreSQL 16 (Datos)
  • • Redis 7 (Cache/Sessions)
  • • NATS 2.10 (Eventos)
  • • Docker Compose / K8s
